# Fajar Motor

Workshop & spare-part store website for **Fajar Motor**, built with [Laravel](https://laravel.com).

## ✨ Features

- Product/catalog pages for motorcycle spare parts
- Workshop service information pages
- Built on the Laravel MVC stack (Blade templates, Eloquent ORM, routing)

## 🚀 Getting started

Requirements: PHP 8.2+, Composer, MySQL.

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

Then open http://localhost:8000 in your browser.
